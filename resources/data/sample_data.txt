## Configuration Notes
- Default window size: 1024x1024
- Theme: Blue primary (#3498db)
- Font: Arial, 12pt
- Auto-save: Enabled

## Usage Instructions
1. Launch the application
2. Choose your mode (Sign or Learn)
3. Enter text in the input area
4. Click process to see the result
5. Use the menu to change modes or settings
